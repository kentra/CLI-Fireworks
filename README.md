# Terminal Fireworks

A Python script that displays animated fireworks in your terminal.

## Features

- Colorful fireworks that launch and explode
- Each explosion spells out "Kentra"
- Particle effects with gravity and fade-out
- Trail effects on rockets
- Adapts to your terminal size

## Usage

```bash
python fireworks.py
```

Press `Ctrl+C` to stop the show.

## Requirements

- Python 3.x
- Terminal with ANSI color support
